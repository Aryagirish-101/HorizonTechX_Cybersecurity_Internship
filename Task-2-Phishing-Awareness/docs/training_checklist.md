# Phishing Awareness Training Checklist

## Learning Objectives

By the end of this training, the learner should be able to:

- [ ] Explain what phishing is.
- [ ] Identify common types of phishing.
- [ ] Recognize suspicious emails and messages.
- [ ] Identify suspicious links and attachments.
- [ ] Understand common social engineering techniques.
- [ ] Respond safely to suspected phishing attempts.
- [ ] Report suspicious messages through the correct channel.
- [ ] Understand the importance of Multi-Factor Authentication (MFA).

## Practical Checklist

Before interacting with an unexpected message:

- [ ] Check the sender address.
- [ ] Check the message context.
- [ ] Look for urgency or threats.
- [ ] Inspect links before opening them.
- [ ] Be cautious with attachments.
- [ ] Never share passwords or OTPs.
- [ ] Verify unusual requests independently.
- [ ] Report suspicious messages.
