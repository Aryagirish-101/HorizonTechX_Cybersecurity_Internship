# Basic Network Sniffer

## Project Overview
This is a simple network packet sniffer built using Python and Scapy. It captures live network packets and displays useful information such as Source IP, Destination IP, Protocol, and Port Numbers.

## Features
- Capture live network packets
- Display Source IP Address
- Display Destination IP Address
- Detect TCP, UDP, and ICMP protocols
- Display Source and Destination Port Numbers

## Technologies Used
- Python 3
- Scapy
- Kali Linux
- Visual Studio Code

## Installation

Install Scapy:

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
sudo python3 network_sniffer.py
```
